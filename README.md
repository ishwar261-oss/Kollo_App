# Kollo 🎨

**Play with colours. Create beautiful patterns. Make your ideas colourful.**

Kollo is a simple and interactive web application designed to make exploring and experimenting with colours easy and enjoyable.

It provides a clean space to generate colour palettes, explore different colour combinations, and work with colours in different formats.

The goal of Kollo is to make colour selection simple, creative, and accessible through an intuitive interface.

## 📌 About the Project

Kollo is a personal project built to explore frontend development and create a practical, user-friendly colour utility.

The project focuses on simplicity, usability, and a clean user experience.
